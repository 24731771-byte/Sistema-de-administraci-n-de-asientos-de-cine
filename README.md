
# Sistema de Administración de Asientos de Cine

## Descripción
Proyecto académico para administrar los asientos de una sala de cine mediante una matriz.

## Funcionalidades
- Mostrar matriz de asientos.
- Reservar asientos.
- Liberar asientos.
- Consultar disponibilidad.
- Contar asientos ocupados y disponibles.
- Calcular porcentaje de ocupación.
